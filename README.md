# 🎬 Netflix Clone

A responsive **Netflix Clone** website built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Netflix with a modern user interface, movie sections, navigation bar, and interactive FAQ functionality.


## 📌 Project Overview

This project was created to practice and demonstrate front-end web development skills using **HTML, CSS, and JavaScript**.

The website is designed to provide a Netflix-inspired streaming platform interface with a responsive layout and interactive elements.

## ✨ Features

* 🎥 Netflix-inspired user interface
* 📱 Responsive design for different screen sizes
* 🧭 Navigation bar
* 🖼️ Movie and content sections
* 🔥 Hero/banner section
* ❓ Interactive FAQ accordion
* ➕ FAQ expand/collapse functionality using JavaScript
* 🎨 Modern styling with CSS
* ⚡ Interactive front-end elements using JavaScript
* 📂 Organized HTML, CSS, and JavaScript files

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling, layout, animations, and responsiveness
* **JavaScript** – Interactive functionality
* **Font Awesome** – Icons

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/netflix-clone.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd netflix-clone
```

### 3. Run the website

Open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.
